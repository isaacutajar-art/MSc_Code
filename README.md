This repositry includes the code used for the implementation of the functional prototype. The repo includes:

1. a folder named "msc_ros2", which includes the ros2 nodes and other setup-related scripts
2. a file named "teensy_vl53l7cx.ino", which includes the C++ code uploaded to teh Teesny 4.1 to acquire data from the 6 ToF sensors
3. a file named "led_ring.ino", which receives data related to LED colors and LED addresses and light up the corresponding LEDs.
